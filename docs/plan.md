# MotorGuard 16 周执行计划

每周投入约 25 小时：8h 看手册/学理论，12h 写代码和焊板，3h 测试，2h 文档与 Git。遇到考试或春节顺延，不压缩测试周。

## 周任务表

| 周次 | 学习重点 | 实现任务 | 验收/交付 |
|---|---|---|---|
| 第1周 | C 指针、结构体、环形缓冲；STM32 时钟/GPIO/UART | 建仓库、BOM、点灯、串口打印 | 系统框图 + BOM v1 + 串口输出 |
| 第2周 | TIM PWM、GPIO、电机驱动 | 24V 电机开环调速、方向控制、电流静态测试 | 示波器 PWM 波形正确；0–3000 rpm 可调 |
| 第3周 | ADC、DMA、输入捕获 | 20kHz 电流采样、霍尔测转速、环形缓冲 | 串口/CSV 输出电流和 RPM；记录采样抖动 |
| 第4周 | SPI、I2C、数据帧 | 振动/温度采集、协议打包、SD 日志 | 3.2kHz 振动数据；SPI 时序正常 |
| 第5周 | FreeRTOS 任务、队列、通知、互斥量、事件组 | 6 任务架构、优先级、CPU/栈水位 | 数据不丢；栈余量 >30% |
| 第6周 | CMSIS-DSP、FFT、窗函数 | 2048 点 FFT、RMS、峰值、峭度、谐波 | 正弦信号频率/幅值误差 <5% |
| 第7周 | 故障机理、测试台 | 不平衡盘、坏轴承、可调负载、四类数据采集 | 数据集 v1；每类 ≥30 组；带 run_id |
| 第8周 | 状态机、阈值诊断 | 诊断逻辑、继电器、SD 日志、MVP | 加配重后 1s 内报警；正常不误报 |
| 第9周 | 控制环、安全、IWDG | 1kHz 速度闭环、堵转/过流/超速保护 | 阶跃响应；故障 100ms 内切断 |
| 第10周 | Modbus、USB、上位机 | 寄存器表、CRC、超时、PC 显示 | PC/PLC 能读数据；断线可恢复 |
| 第11周 | 原理图、PCB、器件选型 | 2 层板设计、ERC/DRC、设计评审 | 原理图/PCB v1；关键测试点齐全 |
| 第12周 | 打样、焊接、bring-up | 电源、时钟、调试口、传感器、电机 | 3.3V/5V 正常；板载跑通 |
| 第13周 | EMI、模拟前端、结构 | 接地、滤波、屏蔽、线束、外壳 | 电流噪声有前后对比；24V 干扰测试 |
| 第14周 | 自适应阈值、轻量分类器 | 均值+3σ、决策树/kNN、CPU/RAM 优化 | 准确率/误报率对比；CPU <70% |
| 第15周 | 稳定性测试 | 24h 连续运行、抖动/延迟/温升/复位测试 | 测试报告；24h 无复位 |
| 第16周 | 作品集与面试 | Demo 视频、README、原理图、简历、面试 | GitHub 仓库 + 3 分钟视频 + 3 条简历 |

## 关键节点

- 第 8 周末：必须有一个能演示的 MVP。
- 第 12 周末：PCB 或扩展底板必须能跑通。
- 第 15 周末：所有指标必须有测试证据。
- 每周日：提交代码并写周报，记录完成、未完成、风险和下周计划。

## 采购顺序

- 第 1 周：主控、ST-Link、电机、驱动、电源、传感器、显示、存储、通信、保护件、线材。
- 第 7 周：轴承座、联轴器、好/坏轴承、配重件、底座。
- 第 11 周：PCB、连接器、外壳、3D 打印件。
- 备件：INA240、ADXL345、BTS7960 各备 1 只。

## 降级方案

时间不够时先保 MVP：电机调速 + 电流/振动采集 + FFT + 不平衡报警 + SD 日志。分类器、Modbus、自定义 PCB 都是加分项，不要一开始全上。

## 风险

- 电机噪声干扰 ADC：低侧采样、RC 滤波、屏蔽线、单独电源、地线整改。
- FreeRTOS 数据丢失：DMA 双缓冲、环形缓冲、溢出计数、任务通知。
- FFT 幅值不准：先用信号源和 Python 参考结果校准，再加窗。
- 故障数据不足：先做可复现测试台，按 run_id 采集，不要随机切窗。
