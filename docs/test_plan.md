# MotorGuard 测试计划

## 1. 指标

| 指标 | 目标 | 测试方法 |
|---|---:|---|
| 电流采样率 | 20kHz | 示波器看 TIM 触发/ADC 转换 |
| 振动采样率 | 3.2kHz | 逻辑分析仪看 SPI 读取周期 |
| 控制环 | 1kHz | GPIO 翻转 + 示波器 |
| FFT | 2048 点 | 正弦信号频率/幅值对比 |
| 频率分辨率 | 约 9.8Hz | `fs/N = 20000/2048` |
| 采样抖动 | <2µs | 示波器测 ADC 触发周期 |
| 故障检测延迟 | <500ms | 注入故障到继电器动作 |
| 识别准确率 | >90% | 四类混淆矩阵 |
| 正常误报 | <5%/24h | 24h 正常运行日志 |
| CPU 占用 | <70% | FreeRTOS 运行时统计 |
| 栈余量 | >30% | 高水位 |
| 连续运行 | 24h 无复位 | 日志和看门狗计数 |

## 2. 分模块测试

### 环形缓冲

- 空、满、回绕、清空。
- 覆盖读写索引和计数。
- 在 ISR/任务并发下检查溢出计数。

### CRC16 / Modbus

- 已知向量 `123456789` -> `0x4B37`。
- 错误 CRC、错误长度、非法功能码、越界数量。
- 正常响应、异常响应、断线恢复。

### FFT / 特征

- 信号源输入 100Hz、1kHz、5kHz 正弦。
- 对比 FFT 峰值频率和幅值。
- 对比 RMS、峰值、峭度、1x 比例和高频能量比例。
- 加 Hann 窗后检查泄漏和主瓣宽度。

### 故障状态机

- 正常 -> 不平衡 -> 正常。
- 正常 -> 轴承 -> 正常。
- 过载、过温、超速、堵转、传感器断线。
- 检查持续性计数和清除计数，避免单帧误报。

### 电机与安全

- 0–3000 rpm 开环调速。
- 1kHz 闭环阶跃响应。
- 堵转、过流、超速、急停。
- 继电器动作时间，PWM 是否立即归零。
- 看门狗复位后的安全状态。

### 硬件与 EMI

- 3.3V/5V/24V 纹波。
- PWM、ADC 触发、SPI、UART 波形。
- 电机启停时 ADC 噪声对比。
- 模拟地和数字地、屏蔽线、RC 滤波前后对比。
- 24V 防反接、保险丝、TVS。

## 3. 测试记录

每个测试保存：

- 示波器截图：`docs/test/scope/weekXX_xxx.png`
- 串口/CSV 日志：`docs/test/log/weekXX_xxx.csv`
- 测试结论：日期、版本、条件、结果、问题、下一步。
- 代码提交号：`git rev-parse --short HEAD`。

## 4. 24 小时稳定性

- 正常状态连续运行 24h。
- 每 10 分钟记录一次 CPU、栈余量、温度、电流 RMS、振动 RMS。
- 统计复位次数、看门狗次数、环形缓冲溢出次数、误报次数。
- 结束后导出日志和曲线，写进测试报告。
